Checking

Connection

The extension and the local server prove to each other that they know the token. The token itself is never sent over the connection.

Run node server/server.js --token to print it. --rotate-token makes a new one.
Must match CBB_PORT on the server (default 17333).
Off cuts every connection at once.

Permissions

Choose what a connected agent may do. Ask shows a prompt on the page and remembers your answer for ten minutes per site. Block refuses outright.

With the second option the agent cannot see or touch your own tabs unless you press "Agent can use it" in the popup.
A brake on runaway loops. 0 means no limit.

Sites

One domain per line, subdomains included. When this list is not empty, every other site is refused.
One domain per line, subdomains included. No tool can read or act on these. Add banks, email and admin panels.
Off by default so an agent cannot probe localhost, your router or cloud metadata addresses. Opening such pages in a tab is controlled by the site lists, not by this switch.

Safety

Comma separated. Added to the built-in list.
Tabs the agent opens always go in the group. Your own tabs join it only while the agent is using them, and leave again afterwards. Tabs already in one of your groups stay where they are.
Removes the "started debugging this browser" bar from tabs the agent stopped using.

Shortcuts: Alt+Shift+P pauses or resumes, Alt+Shift+X is the emergency stop. Change them at chrome://extensions/shortcuts.

Activity log

Open the live monitor

Every command an agent sent, newest first. Typed text and form values are never stored. The server keeps its own copy in ~/.browser-bridge/audit.log.
